# La Ruleta del Pesebre

Juego web interactivo con temática caricaturesca de pesebre.

## Publicación

El sitio está preparado para GitHub Pages y usa únicamente archivos estáticos:

- `index.html`
- `styles.css`
- `app.js`

Para publicarlo: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.

La URL esperada será:

`https://cristianc06.github.io/ruleta-pesebre/`

## Estado

La versión actual ya permite registrar participantes en el navegador, dibuja la ruleta dinámicamente y ejecuta la animación completa del giro. La siguiente fase será reemplazar los elementos visuales provisionales por los assets caricaturescos definitivos y conectar Supabase para compartir los participantes entre dispositivos.
